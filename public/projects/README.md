# Project Screenshots Directory

Place your project screenshots in this directory.

Supported filenames referenced in `data/portfolio.ts`:
- `/projects/project1.png`
- `/projects/project2.png`
- `/projects/project3.png`

Recommended image dimensions: 1200x675 (16:9 aspect ratio) or 1000x750 (4:3 aspect ratio), WebP/PNG format.
If an image file is not found, the portfolio automatically renders a modern visual tech gradient card fallback.
